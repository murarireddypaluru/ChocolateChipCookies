# Chocolate Chip Cookies 🍪

A simple Markdown recipe project — a beginner exercise in writing and organizing documentation with Markdown.

The recipe lives in the [`ChocolateChipCookies-main/`](./ChocolateChipCookies-main) folder:

- **[ingredients.md](./ChocolateChipCookies-main/ingredients.md)** — everything you need (butter, sugar, flour, chocolate chips, a greased pan).
- **[recipe.md](./ChocolateChipCookies-main/recipe.md)** — step-by-step baking instructions (preheat 360–375°F, mix, knead, bake 12–15 min).

Start with the ingredients list, then follow the recipe steps.
