# Chocolate Chip Cookies

A simple, beginner-friendly recipe for homemade chocolate chip cookies. This is
a Markdown practice repo, so the recipe is split across two files that this
README ties together.

## Contents

- **[ingredients.md](./ingredients.md)** — everything you'll need, from butter
  and sugar to the chocolate chips and a greased pan.
- **[recipe.md](./recipe.md)** — the step-by-step method, from preheating the
  oven to pulling out golden-brown cookies.

## How to use

1. Gather the items listed in [ingredients.md](./ingredients.md).
2. Follow the steps in [recipe.md](./recipe.md) in order.
3. Let the cookies cool, then enjoy!

Happy baking!
